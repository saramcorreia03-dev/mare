# Maré

Site de treino e alimentação: plano semanal por "maré" (alta, média, baixa), refeições por dia,
timers de treino, peso por semana e fotos de registo. Funciona no telemóvel e no computador.

Os registos ficam só no aparelho (localStorage). Nada é enviado para lado nenhum.

- Para mudar exercícios, tempos ou refeições, edita a parte de cima do `app.js` (listas `WORKOUTS` e `MEALS`).
- Para passar os dados de um aparelho para outro: Progresso, Exportar dados, e depois Importar dados no outro.
